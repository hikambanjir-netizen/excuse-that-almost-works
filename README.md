A one-line entry for the make.fun "The Excuse That Almost Works" bounty: a
Python program that writes a single excuse — the text a gamer sends their
boss to skip work during GTA 6 launch week — to `/output/entry.txt`.

The excuse never mentions the game. It almost works because of one boring,
specific detail: a root canal that only landed on today because somebody
else cancelled theirs.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to change where
`entry.txt` lands).
